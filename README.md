## ✨ Key Features

- **📊 Live GMP & Kostak Tracker:** Track Grey Market Premium (`₹`), estimated listing price, percentage gain, and exact last-updated timestamp (`dd MMM yyyy, hh:mm a`).
- **📈 Issue Size & Real-Time Category Subscription:** View total IPO Issue Size (`₹ Cr`) alongside live category subscription multipliers for **QIB**, **NII (sNII/bNII)**, **Retail (RII)**, and **Total (`x`)**.
- **⚡ 1-Click All Family Demats Mode:** Record bids across all eligible family Demat accounts in a single tap, and launch your broker's official ASBA / UPI IPO console directly.
- **🗓️ 6-Point IPO Crucial Timeline:** Track Open Date, Close Date, Basis of Allotment, Initiation of Refunds, Demat Credit, and Listing Date.
- **🔐 Bank-Grade Local Privacy:** PAN numbers, BO IDs / Demat Client IDs, and UPI IDs are encrypted locally using Android Keystore (`AES-256-GCM`) and masked by default. Zero external servers or recurring cloud fees.
